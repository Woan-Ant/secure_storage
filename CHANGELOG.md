# 0.1.0

Initial release. Runs on Android, iOS, Web, macOS, Windows and Linux.

- `SecureStorage` service backed by Hive CE boxes, with per-box AES keys
  generated by Hive and stored in the platform keystore via Flutter Secure
  Storage.
- `storeData`, `getData`, `deleteData` and `isDataExist`, plus
  `listEncryptedKeys` and `listUnencryptedKeys` for inspecting what is on the
  device.
- Parameter objects (`ParamCheckData`, `ParamGetData`, `ParamStoreData`,
  `ParamDeleteData`) that normalise box and key names and namespace each key
  under its box.
- Typed exceptions for every failure mode, each mapping to a matching `Failure`
  value.
- `StorageRepository` and six use cases returning dartz `Either<Failure, T>`
  for callers who prefer not to catch. `Either`, `Left` and `Right` are
  re-exported, so consumers need not depend on dartz directly.
- `initSecureStorageFeature` to register the whole feature into a `get_it`
  container, with hooks for Hive type adapters, a substitute
  `FlutterSecureStorage`, and a logger.
- Pluggable `SecureStorageLogger`; silent by default, and never emits encryption
  keys or stored values.

Web support is why the package takes a `storagePath` instead of depending on
`path_provider`, and why the box-file scan sits behind a conditional import —
both `path_provider` and a bare `dart:io` import would exclude web.
